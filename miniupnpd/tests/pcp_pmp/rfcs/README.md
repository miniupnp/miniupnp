# RFC source texts

These plain-text RFCs are kept alongside the PCP/NAT-PMP harness so each YAML
case can be reviewed against its cited specification:

- [RFC 6886](https://www.rfc-editor.org/rfc/rfc6886.txt): NAT-PMP.
- [RFC 6887](https://www.rfc-editor.org/rfc/rfc6887.txt): PCP.
- [RFC 7220](https://www.rfc-editor.org/rfc/rfc7220.txt): PCP DESCRIPTION option.
- [RFC 7652](https://www.rfc-editor.org/rfc/rfc7652.txt): PCP authentication.
- [RFC 7753](https://www.rfc-editor.org/rfc/rfc7753.txt): PCP PORT_SET option.
- [RFC 7843](https://www.rfc-editor.org/rfc/rfc7843.txt): PCP THIRD_PARTY_ID option.

Files are unmodified text downloads from the RFC Editor. The RFCs include their
own copyright and usage terms.
